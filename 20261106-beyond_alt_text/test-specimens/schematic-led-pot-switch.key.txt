# Answer key: LED, potentiometer and switch schematic

Drawn November 5, 2026 for testing (schematic-led-pot-switch.svg). Rick to confirm.

Components: BT1 battery 9 V; S1 single-pole switch; RV1 potentiometer 10 kΩ; R1 resistor 330 Ω; D1 LED.

One series loop:
BT1 + -> S1 -> RV1 end terminal -> RV1 other end, tied to the wiper -> R1 -> D1 anode -> D1 cathode -> BT1 -

Checks (the details a tool could get wrong):
1. All five parts and their values, correct.
2. Connection order, as above.
3. S1 is drawn OPEN. Saying so is right. Saying the LED is lit is a conclusion the drawing doesn't support.
4. The wiper is tied to one end of RV1, so it works as a variable resistor (rheostat).
5. LED polarity: anode toward R1, cathode toward the battery's minus side.
6. Battery polarity: + at the top, toward S1.
7. Doesn't add what the circuit "does" or calculate current, unless asked.
