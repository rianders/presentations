# Answer key: Labanotation specimens

Source: the hand-drawn symbol sheet in the Movement4Brain Game Design Document, section 5.2.
Symbols were cropped from that sheet with their handwritten labels removed, so a model has
to read the symbol, not the word next to it.

## laban-symbols-unlabeled.png (numbered left to right, top to bottom)
1. flexion
2. rotation
3. up / high
4. down / low
5. move away
6. extension
7. stillness
8. middle / horizontal
9. any action
10. jump
11. balance
12. move forward

The level symbols (up/high, down/low, middle) are the same rectangle; only the fill differs:
diagonal hatching = high, solid black = low, a single dot = middle.

## laban-sequence.png (read BOTTOM to TOP; double line = start at bottom, end at top)
This sequence was assembled for testing. It is not a real dance.
1. stillness
2. up / high
3. rotation
4. jump
5. down / low
6. flexion
7. extension
8. stillness

Things to check in the answer:
- Did it read bottom to top, or top to bottom (the common mistake)?
- Did it tell the three level symbols apart by fill?
- Did it say what it could not identify, or name something plausible?
